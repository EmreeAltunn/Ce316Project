IAE — Integrated Assignment Environment

IAE, programlama odevlerini otomatik olarak derleyip calistirip beklenen ciktiyla karsilastiran bir masaustu uygulamasidir.

Contents: Getting Started · Creating a Configuration · Importing / Exporting Configurations · Creating a Project · Adding Test Cases · Running an Assignment · Viewing Results · Troubleshooting

Getting Started

Uygulamayi baslattiginizda ana pencere acilir. Tum veriler kullanici ev dizininizdeki .iae klasorunde bir SQLite veritabaninda saklanir. Tipik akis: once bir Configuration tanimlayin, sonra bir Project olusturun, test case ekleyin ve odevi calistirin.

Creating a Configuration

Configuration > Manage Configurations menusunu acin ve New butonuna basin. Bir konfigurasyon kullanilan programlama dilini tanimlar:

FieldDescription
NameKonfigurasyon adi (benzersiz)
Compiler PathDerleyici yolu, orn. gcc (yorumlanan dillerde bos)
Compiler ArgsDerleme argumanlari, {source} ve {output} kullanir
Run CommandCalistirma komutu, {executable} ve {args} kullanir
Requires CompilationC/Java icin isaretli, Python gibi dillerde isaretsiz
Source / Output FileKaynak dosya adi ve derlenmis cikti adi
Placeholder'lar: {source}, {output}, {executable}, {args} calisma sirasinda otomatik doldurulur.

Importing / Exporting Configurations

Manage Configurations ekraninda Import… ile bir .iaeconfig dosyasini iceri aktarabilir, Export Selected… veya Export All… ile konfigurasyonlari disa aktarabilirsiniz. Bu, konfigurasyonlari ekip arkadaslariyla paylasmayi kolaylastirir.

Creating a Project

File > New Project menusunu secin. Proje adini girin, bir konfigurasyon secin ve iki dizini belirleyin:

  • Submissions Directory — ogrenci ZIP dosyalarinin bulundugu klasor
  • Working Directory — ZIP'lerin acilacagi calisma klasoru

Save Project ile projeyi kaydedin. Daha sonra File > Open Project ile geri yukleyebilirsiniz.

Adding Test Cases

Proje formunda Add Test Case butonuna basin. Her test case icin bir ad, opsiyonel girdi argumanlari ve opsiyonel bir beklenen cikti dosyasi belirtebilirsiniz. Bir test case'i kaldirmak icin tablodan secip Remove Test Case kullanin.

Running an Assignment

Proje formunda Run Assignment butonuna basin. IAE tum ZIP dosyalarini acar, her ogrenci icin kaynak kodu derler (gerekiyorsa), calistirir ve ciktiyi beklenen ciktiyla karsilastirir. Ilerleme cubugu ve canli log calisma sirasinda guncellenir.

Viewing Results

Calisma bitince View Results butonu etkinlesir. Sonuc tablosu her ogrenci icin derleme, calistirma ve test durumunu gosterir. Export CSV… ile sonuclari bir CSV dosyasina aktarabilirsiniz.
