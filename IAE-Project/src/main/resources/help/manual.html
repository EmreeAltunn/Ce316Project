IAE — Integrated Assignment Environment

IAE is a desktop application that automatically compiles and runs programming assignments and compares their output against the expected output.

Contents: Getting Started · Creating a Configuration · Importing / Exporting Configurations · Creating a Project · Adding Test Cases · Running an Assignment · Viewing Results · Troubleshooting

Getting Started

When you launch the application, the main window opens. All data is stored in a SQLite database inside the .iae folder in your user home directory. The typical workflow is: first define a Configuration, then create a Project, add test cases, and run the assignment.

Creating a Configuration

Open the Configuration > Manage Configurations menu and click New. A configuration defines the programming language being used:

FieldDescription
NameConfiguration name (unique)
Compiler PathPath to the compiler, e.g. gcc (leave empty for interpreted languages)
Compiler ArgsCompilation arguments; uses {source} and {output}
Run CommandRun command; uses {executable} and {args}
Requires CompilationChecked for C/Java; unchecked for languages like Python
Source / Output FileSource file name and compiled output name
Placeholders {source}, {output}, {executable} and {args} are filled in automatically at run time.

Importing / Exporting Configurations

On the Manage Configurations screen you can import a .iaeconfig file with Import…, and export configurations with Export Selected… or Export All…. This makes it easy to share configurations with your teammates.

Creating a Project

Select File > New Project. Enter the project name, choose a configuration, and set two directories:

  • Submissions Directory — the folder containing the student ZIP files
  • Working Directory — the working folder where the ZIPs will be extracted

Save the project with Save Project. You can reload it later with File > Open Project.

Adding Test Cases

On the project form, click Add Test Case. For each test case you can specify a name, optional input arguments, and an optional expected-output file. To remove a test case, select it in the table and use Remove Test Case.

Running an Assignment

On the project form, click Run Assignment. IAE extracts all the ZIP files, compiles the source code for each student (if required), runs it, and compares the output against the expected output. The progress bar and live log are updated during the run.

Viewing Results

When the run finishes, the View Results button becomes enabled. The results table shows the compile, run, and test status for each student. You can export the results to a CSV file with Export CSV….

Troubleshooting

ProblemSolution
Compiler not foundVerify the path with Test Compiler on the Configuration screen
ZIP does not extractMake sure the file is a valid, uncorrupted ZIP
All tests FAILCheck the expected-output file path and the run command
Program hangsThe run automatically times out after 30 seconds
